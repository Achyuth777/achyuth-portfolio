## Five patterns selected

1. **Coherent spatial metaphor:** an architectural gate connects the identity, project portals and closing signal. Original geometry; no driving game or copied illustration.
2. **Evidence before spectacle:** named problems, real stack and explicit implementation boundaries, with direct source/demo access.
3. **Progressive exploration:** short entry points lead to full case studies and optional labs; ordinary links remain usable.
4. **Personal editorial rhythm:** large typography alternates with quieter reading, timelines and diagrams.
5. **Useful microinteractions:** project filters, skill-to-project links, approval walkthrough and email copying support actual tasks.

## Motion references

React Bits official documentation and source were inspected at https://reactbits.dev and https://github.com/DavidHDev/react-bits (commit c2a1408d9219a5bd7a2d9c93c9c499042f5fa34a). Vendored Magnet and SpotlightCard retain the original license. Both use React hooks, accept class/style customization and clean up event/animation resources. Magnet supports disabled, magnetStrength, padding, axis, maxOffset, tilt and spring settings. SpotlightCard supports color, intensity, size, softness, shape, proximity and reduced-motion handling. Only these two are shipped. Text reveals are original CSS; this prevents a portfolio assembled from unrelated demo effects.

Motion React docs (https://motion.dev/docs/react), GSAP docs (https://gsap.com/docs/v3/), R3F scaling guidance (https://r3f.docs.pmnd.rs/advanced/scaling-performance), Drei docs and Lenis were consulted. Raw Three.js is dynamically imported for one scene at a time; CSS handles entrances, native scroll remains intact. GSAP, Motion, R3F, Drei and Lenis are deliberately not runtime dependencies.

“MotionVideos AI” could not be reliably identified. motionvideos.ai and motionvideo.ai were inaccessible. https://motionvideoai.com is branded MotionVideo AI and describes AI video generation/character motion transfer, which does not establish that it is the intended web-motion reference. No proprietary code or invented demo analysis is used.
