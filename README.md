# Achyuth PV — Portfolio

A responsive portfolio in the Cyber Ronin visual style, built with plain HTML, inline CSS, and vanilla JavaScript.

## Deploy to Vercel

1. Import `Achyuth777/achyuth-portfolio` as a new Vercel project.
2. Select **Other** as the framework preset.
3. Keep the root directory at the repository root.
4. Leave the Build Command empty (no build step).
5. Use `.` as the Output Directory if Vercel asks for one.
6. Deploy. No dependencies or environment variables are required.

## Run locally

Open `index.html` in a browser, or serve the directory with `python3 -m http.server 8000` and visit `http://localhost:8000`.

## Included

- Responsive navigation and mobile menu
- Cursor and touch spotlight image reveal
- Filterable SupplyLens, TreasuryFlow, and Argus AI projects
- Accessible project-detail dialogs
- About, tech stack, achievements, and writing links
- Email copying and a contact form that opens a mailto draft
- Reduced-motion support

## Notes

Fonts and hero images load from external providers and require an internet connection. The contact form opens the visitor's email app; it does not send or store messages on a server. Project descriptions distinguish MVPs and simulations from production capabilities. Class is displayed as **IT-A**.

JavaScript syntax and internal navigation were checked. Visual browser testing was not available during initial implementation.
